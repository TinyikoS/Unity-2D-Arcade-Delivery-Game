# Delivery Dash (2D Game Development Project)

## Project Description

Delivery Dash is a 2D arcade-style delivery game developed as part of the GameDev.tv 2D Unity course. The project focuses on learning core game development principles using Unity and C#.
In the game, the player controls a delivery vehicle, collects packages, and delivers them to designated locations while navigating obstacles and managing movement speed.

---

## Technologies Used

- Unity (2D Game Engine)  
- C#  
- Visual Studio  
- GameDev.tv 2D Development Framework  

---

## Features

### Player Movement
- Rotation and directional steering  

### Package System
- Pickup and delivery mechanics using trigger collisions  

### Collision & Physics
- Obstacle detection  
- Speed changes on collision  

### Game Environment
- 2D sprite-based environment  
- Camera follow system  
- Basic level design with roads and obstacles  

---

## What I Learned

- How Unity’s component system works  
- Writing C# scripts to control gameplay mechanics  
- Using colliders and triggers for interaction  
- Debugging and testing gameplay functionality
- Designing a level
